Before you begin

Made for Mac and Windows.

Hardware, software and model requirements
You bringWhat to know
A MacmacOS 14 or newer. One universal build for Apple Silicon and Intel: Metal + CPU/Accelerate, AVX2 on Intel.
Or a Windows PCWindows 10/11 x64 with AVX2 and the Visual C++ 2015-2022 x64 runtime. CPU backend.
A diffusion modelMultiple GB of disk and RAM. Use the matching VAE and text encoders for your model family. Weights are not included and have their own licenses.
4D 20+ for integrationInstall the component with its tcp, workers and event dependencies. Direct HTTP use does not require 4D.

CUDA, Vulkan, ROCm, Linux and Windows ARM are not packaged here.

Keep local inference local.

Bind the server to 127.0.0.1. It has no authentication or TLS; 0.0.0.0 exposes generation and model-management APIs to the network.

From download to image

Your first local image.

This path runs the server directly, without 4D. The standalone default port is 1234; these examples use 8080 to match the 4D wrapper.

01

Start the engine on localhost

Shell / macOS
{% highlight shell %} .build/package/macOS/sd-server \ --model "/absolute/path/to/model.gguf" \ --listen-ip 127.0.0.1 --listen-port 8080 {% endhighlight %}

Split model families also need compatible VAE and text encoders; check sd-server --help and the pinned model guides.

02

Wait until the model is ready

Shell / macOS
{% highlight shell %} curl --fail-with-body http://127.0.0.1:8080/sdcpp/v1/models/status {% endhighlight %}

Retry until its state is ready. A started process does not mean the weights have finished loading.

03

Generate and save an image

Shell / macOS
{% highlight shell %} curl --fail-with-body http://127.0.0.1:8080/v1/images/generations \ -H "Content-Type: application/json" \ -d '{"prompt":"A futuristic city, cinematic lighting","size":"512x512","n":1,"output_format":"png"}' \ -o response.json python3 -c 'import json,base64; from pathlib import Path; r=json.loads(Path("response.json").read_text()); Path("image.png").write_bytes(base64.b64decode(r["data"][0]["b64_json"]))' {% endhighlight %}

The response carries base64-encoded image bytes in data[].b64_json, not a download URL. Windows commands are in the standalone server guide.

Connect with tools you know

A familiar API. A local address.

Point AI Kit's OpenAI client at the base URL, not the complete generations endpoint, and request b64_json.

{% highlight 4d %} var $AIClient : cs.AIKit.OpenAI $AIClient:=cs.AIKit.OpenAI.new() $AIClient.baseURL:="http://127.0.0.1:8080/v1" $AIClient.apiKey:="" {% endhighlight %}
